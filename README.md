# Prova+ — N1

Protótipo navegável da plataforma de automatização de provas objetivas.

## Escopo N1
- Telas principais navegáveis
- Dados mockados
- Fluxo de criação de avaliação
- Geração simulada de versões
- Fluxo de correção simulado
- Relatórios e estatísticas demonstrativas
- Interface minimalista

## Tecnologias
- React
- Vite
- React Router
- Lucide React

## Executar
```bash
npm install
npm run dev
```

## Observação
Esta versão é um protótipo da N1. Não possui banco de dados, autenticação real, API, leitura real de imagem/QR Code ou geração definitiva de arquivos.
