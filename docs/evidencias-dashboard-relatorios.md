# Evidências: Dashboard e Relatórios

O projeto compila localmente e os testes cobrem estados de carregamento/erro, seleção de turma e avaliação, exibição dos resultados e geração segura do XLSX.

## Capturas de tela para o relatório individual

As telas com dados reais ainda precisam ser capturadas em uma sessão autenticada ligada a um banco com turmas, avaliações e correções. O ambiente desta execução não possui uma conta de professor nem banco inicializado, então nenhuma imagem de demonstração foi apresentada como evidência real.

1. **Dashboard** — mostrar os indicadores carregados e os atalhos.
2. **Dashboard em erro** — indisponibilidade da API e botão de nova tentativa; pode ser uma captura complementar.
3. **Relatório filtrado** — turma e avaliação selecionadas, resumo estatístico, notas e análise por questão.
4. **Arquivo Excel** — abrir o `.xlsx` baixado e mostrar as colunas e linhas da mesma seleção do relatório.

Antes das capturas, inicie a API e o banco conforme o README do projeto, entre com um professor que tenha correções registradas e selecione os filtros no relatório. Não inclua credenciais ou dados pessoais de alunos nas imagens entregues.
